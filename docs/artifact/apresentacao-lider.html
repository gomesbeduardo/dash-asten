Painel da reunião semanal

Proposta para validar: o que entra na primeira versão, como fica na tela e o que preciso de você para começar.

Teste online, sem login: dash-asten.vercel.app

Primeira versão

Entra

  • Importar a planilha da semana; cada aba vira uma tela
  • Painel pronto em cada aba, já montado para a nossa planilha
  • Filtros em cada aba, com botão para limpar
  • Esconder abas que não interessam na reunião
  • Escolher quais colunas aparecem na tabela
  • Visual pensado para TV, com as cores da Asten

Fica para depois

  • Montar ou editar gráficos pela tela
  • Renomear e reordenar abas
  • Um filtro valendo para todas as abas
  • Exportar imagem ou CSV
  • Salvar preferências entre uma reunião e outra

Tudo roda no navegador. A planilha não sai do computador e some quando a aba é fechada.

Protótipo

Os números são inventados. Montei duas abas de exemplo, indicadores e projetos, porque ainda não sabemos o formato exato da planilha.

Para abrir na máquina: git switch prototipo && cd prototype && npm install && npm run dev
