# Área × SLA — como mostrar em gráfico (pesquisa 16/10)

Ressalva: WebFetch bloqueado; afirmações vêm de resumos de busca, não de leitura integral. Sem regra publicada de n mínimo nem de fonte para TV a 3 m.

Recomendação: **A — duas barras horizontais lado a lado com o mesmo eixo de áreas** (small multiples).
- Esquerda: % no SLA (finalizados no mês), escala fixa 0–100%, rótulo "67% (2 de 3)".
- Direita: SLA vencido (não finalizados), contagem desde 0, vermelho.
- Nome da área uma vez à esquerda; valor na ponta; títulos com a população.
- Uma ordenação só para as duas (ex.: por SLA vencido ou alfabética).
- Mês comparado: mesma regra das listras (D77) ou valor em cinza no rótulo.
Fontes: Datawrapper small multiples https://www.datawrapper.de/blog/small-multiple-column-charts ; eixo duplo https://www.datawrapper.de/blog/dualaxis ; começar no zero https://www.datawrapper.de/academy/why-our-column-and-bar-charts-start-at-zero ; n pequeno https://stephanieevergreen.com/visualizing-small-datasets

Descartadas: dumbbell/dot plot (pontos finos leem mal a 3 m), barra 100% empilhada (só codifica a %), duas seções separadas (perde a linha por área), dispersão (dois eixos, ruim em TV).
Anti-padrões: eixo duplo; % e contagem na mesma escala; % sem n em população pequena; eixo truncado.
